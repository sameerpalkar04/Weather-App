# 🌦️ Weather App

### Simple. Clean. Weather at a glance.

A lightweight weather application that uses the **OpenWeatherMap API** to display weather information through a simple, user-friendly interface.

## Features

- 🌤️ Weather information powered by OpenWeatherMap.
- 🎨 Weather-condition visuals for a more intuitive experience.
- 💻 Simple and lightweight web interface.
- 🌧️ Weather assets for conditions such as clouds, rain, drizzle, and clear skies.

## Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **OpenWeatherMap API** — Weather data

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sameerpalkar04/Weather-App.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Configure your OpenWeatherMap API key if required by the application.
